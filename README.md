# Mii Boba — Website

Website for **Mii Boba (Bubble Tea & Coffee)** — the rebrand of Totally Tea & Boba,
5483 N MacArthur Blvd, Irving, TX 75038 (Market Square).

Single-file build of the site (`index.html` — all assets inlined). Open it in any
browser, or serve the folder with any static host / GitHub Pages.

Brand: logo artwork supplied by the owner, used as-is. Menu, address and hours on
the site are the store's real ones.
